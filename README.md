# codeminder

Code-RAG MCP Server

## Development Principles

This project follows the principles defined in our [Project Constitution](.specify/memory/constitution.md), which governs all technical decisions and implementations:

- **Code Quality First**: Maintainable, testable, well-documented code is non-negotiable
- **User Experience Above All**: Optimize for user success through intuitive interfaces and actionable feedback
- **Simplicity Over Complexity**: YAGNI principles guide all decisions—implement only what's needed now
- **Proper Abstractions**: Abstractions must earn their existence by eliminating genuine duplication
- **Performance Consciousness**: Performance must be adequate and measurable with evidence-based optimization

All contributions must comply with the constitution. See the [constitution](.specify/memory/constitution.md) for detailed principles, technical standards, and governance.
